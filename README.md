# Driver Drone V1 
Este jogo foi desenvolvido para um escape room ministrada pelo capítulo estudantil do **IEEE control system society** cuja finalidade é ensinar pessoas sobre  os princípios básicos da eletrônica e controle. Ele desenvolvido em game maker studio e está inteiramente integrado a um gamepad feito desenvolvido e programado apenas para o controle do jogo!

### -->enredo escape room e jogo:
no jogo você controla remotamente de um bunker uma sonda que tem o objetivo de coletar 3 amostras do antigo mundo para traze-las para dentro para que assim, possam ser estudadas. O robô está equipado com um sonar que precisa ser gerenciado para encontrar as amostras antes que a bateria acabe.
