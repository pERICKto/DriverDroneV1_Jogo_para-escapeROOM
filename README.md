começando o desenvolvimento no 2/3 minigames que precisam estar presentes na versao final do jogo

este minigame tem o objetivo de ensinar o principio mais basico da eletronica, ligado e desligado, passando energia ou não.
A ideia é que o jogador precise alternar LEDS entre ligado e desligado para conversar diretamente com painéis de amostras afim de desbloquear a amostra desejada.

existirao tres pontos de interesse no mapa e dentro de cada ponto, 3 opcoes de amostras diferentes com apenas uma correta

o jogador precisa encontrar um documento que diz qual é a amostra certa, ex "preciso de uma amostra que tenha niveis elevados de Cálcio — 60% Magnésio", os jogadores devem traduzir as abreviacoes da tabela periodica CA e MG para binário e alternar os leds no terminal do  jogo para pegares a amostra correta

diferente do outro minigame, quando o jogador interage com um dos 2 unicos ponto de interesse do mapa rm_1_terra, ele pode escolher 1 dentre 3 amostras que vao dar no final de contas 6 possibilidades diferentes de amostras, cada uma assumindo um valor unico correspondente a cada amostras
